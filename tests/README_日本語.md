# 公開回帰テスト

リポジトリのルートで Python 3.11 のローカル仮想環境を使います。実行用の Docker イメージにはテストや開発依存パッケージを含めません。

```bash
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
python -m scripts.evaluate_rag
```

回帰テストは合成ノート、外部 API のモック、インメモリの Qdrant を使います。実際の API キー・保管庫・本番データベースは不要です。初回はトークナイザーデータの取得にネットワーク接続が必要な場合があります。

| 対象 | 検証する動作 |
|---|---|
| 質問と回答 | 独立質問と追加質問の判定、主題と回答言語の保持、根拠に基づく通常・ストリーミング応答 |
| 検索と根拠 | キーワードとベクトルの検索経路、ファイル名とパスの順位統合、完全な重複と異なる版の区別、根拠チャンクの保持 |
| 同期とキャッシュ | 差分の反映、部分失敗後の再試行、Redis 障害と会話・言語ごとのキャッシュ分離 |

`python -m scripts.evaluate_rag` では**既知の正解チャンクを与えた場合**の根拠保持を検証します。実際の検索成功率や回答の正解率を測るものではありません。別のベクトル検索実験に `--retrieval` を指定した場合のみ有料の埋め込み API を呼び出します。合成ノート10件・質問30件の過去の結果、実行手順、限界は[評価ドキュメント](EVALUATION.md)を参照してください。
